# TEKCLUSTER'26 Website

Frontend-only React + Vite symposium website inspired by the supplied brochure.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Before publishing

1. Replace the Google Forms URL in `src/main.jsx` with the real registration form.
2. Replace the QR placeholder with the official registration/payment QR image.
3. Confirm contact details and event rules.
4. Run `npm run build` and deploy the `dist/` folder to Netlify, Vercel, GitHub Pages, or another static host.
